# 验收与回归

## 自动检查

- JVM：分享文案链接提取、域名边界、API JSON、路由 JSON、URL 编码的 RENDER_DATA、不可访问与畸形页面。
- Android：Room 收藏、重命名与外键级联；0.1.0 JSON 迁移可重入且不覆盖已有编辑。
- Android：Media3 对真实 MP4 提取音轨，输出具有音频且不含视频，并验证时长。
- Compose：音乐库、主题、歌单创建、导入入口、全屏播放和异常分享反馈，保存页面截图。

执行结果以对应提交的 GitHub Actions 日志和测试报告为准。远程站点返回可访问资源的能力不能由本地解析样例测试代替。

## 手动验收

1. 覆盖安装后确认 0.1.0 歌曲仍在；收藏、建歌单、改名、换封面、重启验证数据。
2. 分别导入 MP3/M4A/FLAC/WAV/OGG；尝试损坏文件、空文件与空间不足。
3. 选择带音轨的视频，确认输出可播放；尝试无音轨视频；提取中取消并重新导入。
4. 播放时锁屏、切后台、蓝牙按钮切歌，断开耳机、接电话或由其他应用抢占音频焦点。
5. 调整进度、随机和循环，确认队列与当前播放一致；删除当前歌曲时停止访问其副本。
6. 导出文件到系统文件提供方，用其他播放器打开；确认删除应用副本不影响原始来源文件。
7. 自定义图片、字体、主题色、透明度与模糊，重启验证。开启低性能模式检查动画与模糊关闭。
8. 从抖音系统分享和粘贴入口测试短链/长链、不可访问链接与断网。解析成功后只在确认保存时下载；失败可进入本地视频。

0.1.0 的本地导入与播放已由项目发起人在手机上验证。本版本新增功能的跨厂商蓝牙、省电策略及真实抖音链接仍需相应设备与可用资源验证，不能仅凭构建通过推定全部真机兼容。
